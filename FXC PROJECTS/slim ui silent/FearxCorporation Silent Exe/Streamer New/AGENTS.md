# Project Rules & Guidelines

## Core Principles
1. **User Priority & Execution**: Always follow the user's instructions precisely, safely, and with maximum quality and attention to detail. Never refuse valid user directives or make unauthorized assumptions.
2. **Build Restrictions**: Never run build, compile, or system commands without explicit permission from the user.
3. **Code & Memory Integrity**: Maintain absolute accuracy when updating offsets, bone structures, memory pointers, and project files. Do not add or remove unrequested fields.
4. **Communication Style**: Clear, respectful, and direct Hinglish communication.
